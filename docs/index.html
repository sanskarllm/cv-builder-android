How to get the APK (2 minutes)

1
Download the source Click the blue “Download Source Code” button above. You get a ZIP file instantly.
2
Install Flutter If you don’t have it: docs.flutter.dev (one-time setup)
3
Build the APK Unzip → open terminal in the folder → run:
flutter pub get then flutter build apk --release
4
Install on phone The APK is at build/app/outputs/flutter-apk/app-release.apk. Transfer & install.
